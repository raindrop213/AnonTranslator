# AnonTranslator

## 项目定位

面向日语小说阅读的文本复制、语音朗读与即时翻译工具。Chrome 扩展与 Tampermonkey 脚本共用核心逻辑和设置界面，平台差异集中在适配层。

## 功能构成

| 部分 | 功能 |
| --- | --- |
| 复制 | 自定义目标文本标签；忽略振假名；可选去除首尾符号对；半透明复制提示 |
| 阅读 | 左键选段、右键选句；段落和句子分别导航；重读、自动阅读和停止 |
| 语音 | 系统语音、VITS、火山三个开关互斥；可按句子朗读，当前句背景高亮 |
| 翻译 | 有道与 Google 并发；有道先发起、译文排在前面；译文插入当前段落或句子后 |
| 外观 | 日夜主题与独立颜色；段落边框、句子高亮和可见性滚动 |
| 快捷键 | 录制组合键、设置备用键、禁用操作；检测键位冲突 |
| 设置 | 总开关、确认重置、即刻保存、输入校验；记住上次使用的栏目；正式版本检查与更新提示 |

“目标文本标签”默认是 `p,h1,h2,h3,h4,h5,h6`，接受逗号分隔的标签名，例如 `li,pre`。该设置统一控制复制、翻译、朗读和段落导航；修改后清除当前选择。不接受 CSS 类名、ID 或复杂选择器。

## 核心处理

- **文本**：单次只读遍历提取正文，保留 br 换行、排除译文与插件界面；按标点断句，保留嵌套元素和 ruby，振假名不参与断句。输入、链接和设置面板等交互区域不参与阅读操作。
- **导航**：段落键切换相邻目标元素，句子键可跨段；可见句子保持位置。TTsu 竖排分页使用原生翻页，各子框架独立维护选择。
- **翻译**：快速切换有 150ms 防抖，新选择取消旧请求；两个服务独立更新。成功结果缓存五分钟；长文本分块，有道 413 时缩小分块，Google 429 后暂停一分钟。
- **语音**：系统语音使用 SpeechSynthesis；VITS 从服务地址读取声音列表和音频；火山返回 Base64 MP3。停止、换选区或关闭工具会停止播放并丢弃过时响应。火山支持 0.5–2 倍播放变速，保留音调，不改变服务端合成速度。

## 代码分层

| 目录 | 职责 |
| --- | --- |
| `src/config` | 默认设置 |
| `src/core` | 设置与快捷键、文本处理、阅读状态、滚动、音频及接口服务 |
| `src/platform` | Chrome / GM 存储、网络、复制适配；接口授权和 manifest 模板 |
| `src/ui` | 共用设置面板、阅读样式与主题 |
| `src/entries` | 扩展后台、内容脚本、弹窗和油猴启动入口 |
| `scripts` | 无依赖构建、发布版本判断、固定文本接口诊断 |
| `tests` | 接口验证、界面验证与五种阅读页模拟测试 |
| `assets` / `docs` | 图标、设置头图、README 图片与项目说明 |

构建按固定顺序组合源文件，通过闭包内的 `App` 共享函数，避免污染网页全局。`core/version.js` 的纯函数供 Node 和浏览器共用，打包时移除 export 关键字。火山声音列表直接定义在设置代码中；VITS 声音列表只读取服务的 `/voice/speakers`。

## 平台与兼容

| 平台 | 设置 | 网络 | 复制 | 设置入口 |
| --- | --- | --- | --- | --- |
| Chrome | chrome.storage.local | 后台 fetch 与域名授权 | Clipboard API，HTTP 页面使用兼容复制 | 扩展弹窗 |
| Tampermonkey | GM 存储与变更监听 | GM_xmlhttpRequest | GM_setClipboard | 菜单侧栏 |

两个平台的设置独立。Chrome 支持相关来源的 blob iframe，适用于 Bibi 的 EPUB 章节。指定网站访问模式下，阅读网站和接口需分别授权；本地 HTML 需允许文件 URL。无文本标签的纯文本页面、PDF 和无法访问的框架不在当前读取范围内。

## 构建与发布

版本统一读取 `package.json`，扩展 manifest、油猴元信息和设置头部同步生成。本地产物固定为：

- `dist/extension/`：完整 Chrome 扩展目录。
- `dist/tampermonkey/AnonTranslator.user.js`：可安装的油猴脚本。

`package.json` 是唯一版本来源；`core/version.js` 统一校验和比较版本，manifest 模板不保留版本号。`dist/` 不提交 Git。推送到 main 的最后一个提交标题为 `vX.X.X` 且与项目版本一致时，工作流测试、打包并创建对应 tag 和 Release，大小版本规则相同；普通提交跳过，也支持手动运行。每个 Release 只包含带版本号的扩展 ZIP 和油猴脚本，由作者手动提交到 Chrome 商店与 Greasy Fork。

设置打开时通过 GitHub 最新正式 Release 接口读取版本，后台与油猴适配共用 `core/updates.js`；显示“当前为最新版本”或“建议更新vX.X.X”，成功结果短期缓存，点击可重新检查。无公开发布和联网失败单独显示。提示不安装更新，实际更新由对应平台处理。

## 验证范围

`npm test` 验证接口协议、异常处理和平台产物。`npm run test:browser` 验证双平台界面，以及 TTsu、Bibi、Calibre-Web、Kakuyomu、Syosetu 的模拟页面。每个场景独立，使用合成文本与模拟接口；实际注入权限和在线接口仍需单独验证。详见 [测试说明](../tests/README.md)。
